# FocusLens: Real-Time Student Engagement Monitor

**Author:** Haamid Iman
**Course:** ITAI 1378

## Overview
FocusLens is a computer vision application designed to monitor student attentiveness during online lectures. It uses a webcam feed to detect facial landmarks and calculates the Eye Aspect Ratio (EAR) to classify a student's state.

## Features
- **Real-time Face Detection:** Utilizes Dlib's HOG face detector.
- **Drowsiness Detection:** Calculates EAR to detect closed eyes.
- **Status Classification:** Outputs states: `Attentive`, `Drowsy`, or `Absent`.
